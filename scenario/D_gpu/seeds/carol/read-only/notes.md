# 網路筆記（Carol，網路 / 連線）

【從外網連回實驗室機器 — 我們環境特有、外面查不到】
實驗室對外 NAT 沒開 port forwarding，網管也不給設。要從家裡連進來，唯一可行的是
走我們架的 Tailscale。重點是這兩個只有我們內部知道的值：
- 要連的 tailnet 叫 **lab-7f3a**（加入這個才看得到實驗室機器）。
- 實驗室防火牆只放行 **UDP 41641** 這個埠，其他全擋；連線打洞一定要走這個埠。

（這是我們實驗室的私有設定，通用教學只會說「用 VPN」，不會知道是 lab-7f3a / 41641。）

我之前跟硬體組的 Dave 一起弄過機房的網路，所以有他的聯絡方式。
