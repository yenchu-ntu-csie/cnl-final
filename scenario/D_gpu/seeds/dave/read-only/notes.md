# 硬體踩雷紀錄（Dave，系統 / 硬體）

【機房那批舊卡的地雷 — 沒碰過的人絕對不知道】
機房那批舊卡是 NVIDIA K40。實際裝到報廢一台才換來的兩條規矩：
- 驅動只能鎖 **CUDA 11.4**（連 11.8 都會掛，不是只有 12 不行）。
- 開機前 BIOS 一定要關 **Above 4G Decoding**，不然這張卡會讓整台開不了機。

所以這台要動 GPU 之前，先確認 **CUDA 11.4 + BIOS 關 Above 4G Decoding**。

（這兩條是這批卡特有的，網路上查「K40 安裝」也查不到「就是 11.4、就是 Above 4G Decoding」。）
